# 🖥️ Projeto Linux: Automação de Servidor Web Caseiro

**Autor:** Erikociber  
**Área de estudo:** Linux, Administração de Servidores e Automação  
**Projeto:** Criação automatizada de um servidor web utilizando Shell Script

## 📌 Sobre o projeto

Este projeto faz parte da minha jornada de aprendizado em Linux e administração de servidores.

Durante meus estudos, estou aprendendo como o Linux é utilizado na infraestrutura de tecnologia, especialmente em servidores web, servidores de arquivos e servidores de banco de dados.

Neste laboratório, desenvolvi e testei um **script Shell para automatizar a instalação e a configuração de um servidor web**, demonstrando como podemos simplificar tarefas administrativas utilizando comandos e scripts no Linux.

O objetivo foi verificar, na prática, se o script conseguiria preparar o ambiente automaticamente para disponibilizar uma página web.

## 🌐 Como funciona o servidor?

Este é um servidor web caseiro, executado dentro da minha própria rede local.

Ele não está hospedado em um serviço de hospedagem pública e, por isso, **não está disponível diretamente para qualquer pessoa na internet**. O acesso é destinado aos dispositivos que conseguem se comunicar com o servidor pela rede configurada.

Não publiquei o servidor em uma hospedagem externa porque o objetivo deste projeto é estudar, testar e compreender seu funcionamento em um ambiente controlado.

Mesmo assim, você pode utilizar o script como base para montar seu próprio laboratório e criar um servidor web na sua casa.

## ⚙️ O que o script permite fazer?

- Automatizar etapas da instalação e configuração de um servidor web.
- Preparar o ambiente para disponibilizar uma página HTML.
- Reduzir a necessidade de executar manualmente cada comando de configuração.
- Reutilizar o procedimento para criar outros ambientes de servidores web.
- Utilizar diferentes arquivos HTML para disponibilizar páginas distintas, conforme a configuração de cada servidor.
- Praticar comandos Linux, Shell Script e administração básica de servidores.

**Importante:** neste projeto, não desenvolvi o conteúdo visual de uma página web. Meu foco foi testar a automação e confirmar que o script executa as etapas necessárias para preparar o servidor e disponibilizar o arquivo de página utilizado no teste.

## 🧪 Ambiente de laboratório

O servidor foi configurado em um ambiente Linux dentro da minha rede doméstica.

Durante o processo, pratiquei conceitos relacionados a:

- Linux e administração de sistemas.
- Shell Script e automação de tarefas.
- Instalação e configuração de serviços.
- Servidores web e arquivos HTML.
- Endereçamento IP e rede local.
- Testes de funcionamento e acesso ao serviço.

## 🔁 Como replicar o projeto

Você pode utilizar este repositório como referência para construir seu próprio servidor web caseiro.

1. Prepare uma máquina Linux ou uma máquina virtual.
2. Consulte o script disponível neste repositório.
3. Revise os comandos e ajuste as configurações conforme seu ambiente.
4. Execute o script com as permissões necessárias.
5. Utilize o arquivo HTML desejado para testar a disponibilização da página.
6. Verifique o acesso ao servidor a partir de um dispositivo da mesma rede.

Se quiser criar páginas diferentes, poderá adaptar o script para utilizar outros arquivos HTML e ajustar o diretório ou as configurações de cada instalação.

Antes de executar, revise o conteúdo do script e confirme os caminhos, os pacotes e as configurações de rede utilizados.
